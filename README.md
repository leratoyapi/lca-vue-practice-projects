# 🍽️ Cape Town Food Fest – Ticket Landing

A modern, interactive single‑page web application built with **Vue 3** to showcase ticket tiers for the Cape Town Food Fest. Users can browse Bronze, Silver, and Gold ticket packages, see their benefits and prices, and “favourite” a tier to simulate engagement.

This is the foundation for a future ticketing system.
